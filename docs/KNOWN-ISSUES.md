# 已知问题与未验证项

1. **尚无 Apple 编译证据。** Windows 无 Swift/Xcode/Apple SDK；静态检查不证明类型检查、链接或安装通过。
2. **尚无真实账号联调。** 登录、Cookie 和列表适配依据固定提交源码；服务端现状、风控、地域网络和会员限制仍需用户账号验证。
3. **播放器代码未经过 Apple 编译或设备验收。** 已有 PlaybackCoordinator、AVPlayer 页面、续播/进度保存和有限恢复代码。夸克适配器提供 Cookie、Origin、Referer 和 UA；AVURLAsset 的公开选项没有任意 Origin/Referer 头设置能力，当前实现只传 Cookie/UA 并会记录该限制。真实播放是否成功未知。
4. **参考仓库只证明下载接口。** 没有经过核实的转码/HLS 播放接口；不能虚构 video-play API。下载 URL 可能还依赖 Cookie、Referer、Origin、UA，AVPlayer 兼容性尚未确认。
5. **容器和编码兼容性未知。** MKV、AVI、特殊音轨、字幕以及 HDR/Dolby Vision 需真实样本与机型验证。文件扩展名判断仅用于浏览标识。
6. **部署目标待设备确认。** tvOS 16 是暂定 API 基线，不是用户设备已确认；后续需建立兼容矩阵。
7. **重新登录的历史连续性未解决。** 本地 accountId 随凭据保存；新扫码分配新分区以防串账号。稳定服务端身份字段未经验证，暂不自动合并历史。
8. **tvOS 历史只是本地基础。** SQLite 仓库已接入播放器与历史页面；系统可清理本机缓存，不能承诺跨设备同步或永久保留。
9. **媒体库尚未完整交付。** 递归扫描、文件名解析、TMDB 搜索/候选评分与网盘文件搜索已有代码；已确认匹配的 SQLite 缓存和手动确认流程已写；海报墙、详情、完整分季分集、收藏和手动/自动下一集代码已写，真实样本验收待做。
10. **图标和发布资源未完成。** 本轮工程面向开发构建；App Store/TestFlight 发布前还需品牌资源、隐私说明、签名与分发验收。
11. **二维码和会话有效期不是固定合同。** UI 3 分钟超时只是等待上限；不把源码中的 7 天默认值当作真实 Cookie TTL。没有已核实的 refresh-token API。
12. **无自动绕过鉴权。** 401/403/429、未知业务拒绝和下载重定向会明确报错；不会冒充会员、伪造成功或无限重试。

本轮没有 AList/OpenList/WebDAV/自建代理，也没有个人 Cookie、TMDB 密钥或账号明文写入源码。
